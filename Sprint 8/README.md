## Resumo

### AWS Lambda e API
Nesta Sprint, aperfeiçõei  meus conhecimentos em `Spark`, utilizando a plataforma `AWS Glue` para desenvolvimento, criação de `Crawlers` para extrair as tabelas.

Técnicas aperfeiçoadas foram:

- Controle de Acesso com `IAM`.
- Vantagens do `Parquet` sendo ideal para consultas rápidas e uso em `data lakes`.
- Manipulação de Dados com `Apache Spark`.
- Criação de `Crawler` para integração com ferramentas de Consulta.
