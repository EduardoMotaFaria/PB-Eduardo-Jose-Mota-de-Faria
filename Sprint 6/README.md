## Resumo

### S3 AWS e Boto3 em Python
Nesta Sprint, aperfeiçõei  meu conhecimento em `boto3`, uma biblioteca em python utilizada para interagir com os serviços da `AWS`. Configuração de credenciais da `AWS`, Trabalhar com objetos em buckets, Criação de buckets. Também Aperfeiçõei meu conhecimento em `Docker`.

Técnicas aperfeiçoadas foram:

- Utilizando comandos para configuração de Credenciais: `AWS Configure`.
- Gerenciamento de Buckets: `Upload`,`Dowload`, `Criação de Buckets`, `Listagem de Buckets`.
- Lidar com erros e exceções: `except`.
- Automação de Script: `boto3.resource`.
- Utilização de comandos para configuração de Imagem: `COPY`, `CMD`, `WORKDIR`, `FROM`, `RUN`.
- Gerenciamento de Contêineres: `Docker Run`, `Docker Build`.
- Criação do `Dockerfile`.
