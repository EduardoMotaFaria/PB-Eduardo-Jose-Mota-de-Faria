## Resumo

### AWS Lambda e API
Nesta Sprint, aperfeiçõei  meus conhecimentos em `AWS Lambda`, desenvolvendo código e executando sob demanda, criação de `Layers` para extrair bibliotecas utilizada no código.

Técnicas aperfeiçoadas foram:

- Autenticação com chave de `API`.
- Criação de funções `Lambda` para consumir dados da `API` TMDB.
- Exposição de endpoints para consumo de dados.
- Entendimento da utilização de uma `API`.
- Testes, monitoramento e deploy de funções `Lambda`.
