## Resumo

### Docker e Programação Funcional
Nesta Sprint, aprendi a trabalhar com `Docker` desenvolvendo habilidades em criação e configuração de imagem, Gerenciamento de Contêineres, Configuração de Redes `Docker`, Criação de ambientes Independentes. Também tive a oportunidade de trabalhar com `Python`, utilizando a `Programação Funcional`.

Meus principais aprendizados foram:
- Utilizando comandos para configuração de Imagem: `COPY`, `CMD`, `WORKDIR`, `FROM`.
- Gerenciamento de Contêineres: `Docker Run`,`Docker Stop`, `Docker Build`, `Docker Logs`, `echo`, `Docker ps`.
- Configuração de Redes: `Docker -P`.
- Remoção de Contêineres e Imagem: `Docker RM`, `Docker RMI`.
- Criação do `Dockerfile`.
