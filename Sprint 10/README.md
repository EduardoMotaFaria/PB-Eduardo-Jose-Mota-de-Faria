## Resumo

### AWS Lambda e API
Nesta Sprint, adquiri conhecimentos na ferramenta `AWS QuickSight`, desenvolvendo um `Dashboard` para uma visualização de análises melhor.

Conhecimentos adquiridos foram:

- Conexão com diversas fontes de dados.
- Importação de arquivos CSV, JSON, Parquet, etc.
- Uso de filtros e parâmetros para personalização de dados.
- Tipos de gráficos disponíveis.
- Personalização de visualizações e temas.
