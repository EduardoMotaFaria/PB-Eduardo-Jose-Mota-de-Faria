## Resumo

### S3 AWS e Boto3 em Python
Nesta Sprint, aprendi a trabalhar com `boto3` uma biblioteca em python utilizada para interagir com os serviços da `AWS`. Configuração de credenciais da `AWS`, Trabalhar com objetos em buckets, Criação de buckets. Também Aperfeiçõei técnicas de manipulação de dados, utilizando diversas funções em `Python`.

Meus principais aprendizados foram:

- Utilizando comandos para configuração de Credenciais: `AWS Configure`.
- Gerenciamento de Buckets: `Upload`,`Dowload`, `Criação de Buckets`, `Listagem de Buckets`.
- Lidar com erros e exceções: `except`.
- Automação de Script: `boto3.resource`.
