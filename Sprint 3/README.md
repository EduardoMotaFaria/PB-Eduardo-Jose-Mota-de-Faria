## Resumo

### Python e Jupyter Lab
Durante a Sprint, aprendi a trabalhar com `Python` desenvolvendo habilidades em manipulação e análise de dados. Também tive a oportunidade de trabalhar com `Jupyter Notebook`, com funções de análises e manipulação de dados com a biblioteca`Pandas`, plotagem e personalização de gráficos com a biblioteca `Matplotlib`.

Meus principais aprendizados foram:
- Criar gráficos personalizados.
- Filtrar e manipular dados.
- Interatividade e Experimentação.
- Conceito fundamentais de `Python`.
